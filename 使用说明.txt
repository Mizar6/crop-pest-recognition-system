最新完整版（含数据集与训练模型）
打包时间：2026-11-05
========================================

【为什么有这个包】
GitHub 上的版本不是最新。这个包是从开发机直接打包的完整版本，
包含全部代码、数据集、训练权重、数据库数据，以及答辩用的文档。

--------------------------------------------------
一、包里有什么
--------------------------------------------------
server/            后端全部代码（FastAPI + MySQL）
                  含 已训练模型、知识库向量、知识图谱数据
web-v4/            前端全部代码（Vue3 + Vite），含已构建的 dist
train_project/     训练工程
  plantdiseases/     数据集（训练集 + 验证集，30 类）
  最终权重/best.pt    最终训练出的模型权重
  yolo26s.pt 等       各阶段权重
  训练脚本            retrain.py 等
数据库脚本/         数据库导出文件，含病虫害图鉴、药剂、知识库全部数据
docs/               设计文档
答辩相关文档        答辩材料、三个问题的答辩稿、团队收获与体会
README.md           项目说明

--------------------------------------------------
二、跑起来
--------------------------------------------------
第 1 步 建库导入数据
   mysql -uroot -p < 数据库脚本\db_plant_diseases.sql
   数据库连接参数在 server\.env 里，默认 root / 123456 / db_plant_diseases

第 2 步 启动后端
   cd server
   pip install -r requirements.txt
   python -m uvicorn main:app --host 127.0.0.1 --port 8001

第 3 步 启动前端
   cd web-v4
   npm install
   npm run dev -- --port 5176
   浏览器打开 http://127.0.0.1:5176

--------------------------------------------------
三、这一版修过的问题（GitHub 上的旧版没有）
--------------------------------------------------
1. 药剂图鉴的数据与接口：药剂表从防治方案里抽取生成，关联表建立药剂与病害关系，
   列表按能治的病数排序，药名唯一约束防重复。
2. 模型切换：切换模型后类别名按模型身份重新映射，避免类别顺序不同导致知识对错位；
   只有训练出来的模型才受精度阈值约束，上传的权重不受限制。
3. 逐字流式输出：修复了回答只冒出几个字就停住的问题。
4. 实时检测页左侧区域与摄像头画面的高度对齐。
5. 全站统一视觉风格（纸张底色、衬线标题、赭红主色）。
6. 数据处理的清洗、去重、类别均衡、增强模块。

--------------------------------------------------
四、数据集与模型
--------------------------------------------------
数据集        train_project\plantdiseases（30 类，约 2300 张图，含验证集）
最终模型      server\data\models 里的权重 + train_project\最终权重\best.pt
模型指标      mAP@0.5 约 0.3357（120 轮，batch 16，imgsz 640）

如果要自己重新训练：
   把 train_project\plantdiseases 打成一个 zip，在系统的「模型训练」页上传即可，
   页面会自动校验格式、切分验证集、训练并注册新模型。

--------------------------------------------------
五、注意事项
--------------------------------------------------
1. server\.env 里的 DASHSCOPE_API_KEY 需要换成你自己的，否则 AI 问答不可用；
   识别、图鉴、图谱、记录等功能不受影响。
2. MySQL 密码如果不是 123456，改 .env 里的 DB_PASSWORD。
3. 前端如果 npm install 很慢，可以设置国内镜像。
4. 知识库向量文件在 server\data\vstore，不要删，删了问答检索就失效。
